# Sprint 4 Retrospective


## What Went Well

1. Grafana Cloud has been successfully connected
2. Synchronization with other calendars was enabled.
3. The ability to enter timezones, quiet hours, and view daily plans has been added.

## Problems Encountered & Solutions

### Problem 1
- We have task dependencies that slow down the workflow.

#### Description 
- Work for one team member often depends on another member's completed task.

#### Root Cause
- Our project tasks are logically connected and often must follow a specific order.

#### Solution Applied 
- We will try to identify and prepare at least one independent task for each member to work on during waiting periods.


### Problem 2
- Problem with Grafana Cloud connection

#### Description 
- None of our team has worked with Grafana Cloud yet

#### Root Cause
- The team had no knowledge and experience using Grafana Cloud

#### Solution Applied 
- The guides and the reading of the documentation were studied
